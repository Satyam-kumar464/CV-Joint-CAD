## 📌 Overview

This project presents the 3D CAD modelling and assembly of a **Constant Velocity (CV) Joint** used for transmitting rotational motion between two shafts while maintaining a constant angular velocity relationship.

The model was developed in **SolidWorks**, focusing on mechanical component modelling, assembly, geometric constraints, and the working mechanism of the joint.

---

## ⚙️ Working Principle

A CV joint transmits torque between two shafts while allowing the shafts to operate at an angle.

Unlike a conventional universal joint, a CV joint is designed to maintain a **constant output angular velocity** even when the operating angle between the input and output shafts changes.

The joint uses specially designed raceways and rolling elements to transmit torque while accommodating angular movement.

---

## 🔩 Main Components

The CAD assembly consists of:

- **Outer Housing / Outer Race**
- **Inner Race**
- **Cage**
- **Balls**
- **Input / Output Shaft**
- **Retaining Features**
